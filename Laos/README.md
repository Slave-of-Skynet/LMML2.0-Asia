# Laos — Bad BOMB

Align green-shell objects, compute anomaly signals and rank all delivered PNGs.

## Run

Use a separate Python environment. Run from this country directory.

```bash
python -m pip install -r requirements.txt
mkdir -p outputs
python solve.py --images /path/to/images --output outputs
```

## Input and output

All input PNG images. Do not assume the count printed in the story equals the delivered file count.

Obtain task materials from the organizer task card; preserve their original filenames. Generated results belong in `outputs/` or another directory outside Git.
