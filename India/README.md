# India — Twins Separated at Birth

Match transformed image twins using geometry and image descriptors with bounded memory.

## Run

Use a separate Python environment. Run from this country directory.

```bash
python -m pip install -r requirements.txt
mkdir -p outputs
python main.py
```

## Input and output

test-input.zip, or the input location specified by the organizer runner.

Obtain task materials from the organizer task card; preserve their original filenames. Generated results belong in `outputs/` or another directory outside Git.

Organizer material: [source 1](https://drive.google.com/drive/folders/1i9HpSq7yYWfLxN_7kEbSlqY66aYPiF6M).
