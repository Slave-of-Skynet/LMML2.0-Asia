# Bhutan — The 300-Year Old Tiger Nest Painting

Reassemble image strips using directed boundary compatibility and assignment optimization.

## Run

Use a separate Python environment. Run from this country directory.

```bash
python -m pip install -r requirements.txt
mkdir -p outputs
python main.py --input /path/to/materials/input --output-dir outputs
```

## Input and output

The organizer PNG strips, preserving input subdirectories.

Obtain task materials from the organizer task card; preserve their original filenames. Generated results belong in `outputs/` or another directory outside Git.

Organizer material: [source 1](https://drive.google.com/drive/folders/1L4L9B9ui35VR5XzGGiv2yBTyqltQCY4D).
